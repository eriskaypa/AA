## REQ-F1-01: give `Docs/PROGRESS.md` an owner in the path table
Target: `Docs/OWNERSHIP.md` §2 (owner lead / architect) — ARCHITECTURE.md §1.2, §12.2
Need: a row for `Docs/PROGRESS.md`, the port's running record (created before Stage F1, outside every owner's
paths). Proposed: shared — every stage and wave agent may edit only its own table row and append log lines; the
lead resolves merge conflicts in it.
Why: the user's standing rule is to keep the project's progress record updated in the same change as the code, and
F1 already did (commit c392a3f). Without a row, `Scripts/check-ownership.sh` would reject every agent's update as an
unowned path.
Workaround in place: `Scripts/check-ownership.sh` (`owner_of`) treats `Docs/PROGRESS.md` as shared (`*`), marked
with a comment. Change that one line if the lead assigns a single owner.

Resolution: applied — DECISIONS REQ-F1-01 ruling: Docs/PROGRESS.md is the lead's/integrator's, kept shared (`*`) in check-ownership.sh; agents write Docs/Progress/<id>.md, mapped in owner_of (f556cb5)

## REQ-F1-02: allow the UTF-8 write of an autosave off the main actor
Target: `Docs/ARCHITECTURE.md` §2.3 (owner lead / architect) — V2-SCALE finding "every autosave serialises the
whole model on the main thread"
Need: amend the binding algorithm so `backgroundSaveIfDirty` / `save()` snapshot `ModelCodec.encodeAppData` (the
`JSONValue` tree, main actor) and hand the immutable tree to the ordered writer, which runs `JSONWriter.data` before
encrypting and writing. Range errors (Int32) stay synchronous (they come from the encoder's issue log); the
depth > 64 failure would arrive through the writer's completion, which then rolls the stamp back like a write error.
Why: 418 ms of main-thread time per save on a 70 MB file (release, Apple Silicon); about 60 % of it is the UTF-8
writing. Older ship laptops will be slower.
Workaround in place: none; the cost is recorded in Deviations/F1.md ("Save on main").

Resolution: open — lead ruling needed (ARCHITECTURE.md §2.3 is the lead's); not applied in round 2.
