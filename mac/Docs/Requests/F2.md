# F2 — contract change requests (ARCHITECTURE.md §12.3)

## REQ-F2-01: `SavedListOrder.groupEntries` should not return an optional
Target: `Sources/AACore/Services/SavedListOrder.swift` (owner F2) — ARCHITECTURE.md §6.5
Need: `public static func groupEntries(_ data: AppData, groupID: UUID?) -> [(template: ChecklistTemplate, group: String?)]`
(non-optional). 02 REPO-135's "or nil" describes the *group name* paired with each entry (nil when `groupID` is nil,
the group no longer exists or its name is empty), not the result.
Why: the optional result has no meaning in the spec; callers (W-PDF's "Export group (PDF)…") would need a
pointless `?? []`.
Workaround in place: the signature is kept exactly; the function never returns nil (documented in its comment), so
callers may force-unwrap or use `?? []` until the lead changes the signature.

Resolution: rejected — DECISIONS REQ-F2-01 ruling stands: the published optional signature is kept (it never returns nil; callers use `?? []`); no caller benefits enough to amend ARCH §6.5 post-wave (no commit)

## REQ-F2-02: quick-switcher rows need the session lock state
Target: `Sources/AACore/Services/QuickSwitcherScoring.swift` (owner F2) — ARCHITECTURE.md §6.5
Need: make `@MainActor public static func rows(store: AppStore, isGated: (HierarchyItem) -> Bool) -> [Row]` part of
the contract (W-QUICK passes `env.locks.isGated`), keeping `rows(store:)` as the conservative default.
Why: DECISIONS 08 OQ-8 gates locked descriptions from ranking; "locked" is session state held by `ItemLockService`,
which `rows(store:)` cannot see (search already takes `isGated` the same way).
Workaround in place: the overload exists (additive public API in F2's own file); `rows(store:)` treats every
password-protected item as gated, which is the safe reading of OQ-8.

Resolution: applied — ruled before Stage W; `QuickSwitcherScoring.rows(store:isGated:)` is contract and W-QUICK passes `env.locks.isGated` (QuickSwitcherPanelController); listed in DECISIONS "Contract amendments (post-wave)" (this docs commit)
