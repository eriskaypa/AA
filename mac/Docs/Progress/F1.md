* **D-5 (V-01, DATA-080)** — changing the app password no longer orphans legacy `enc:` bodies silently.
  `PasswordService.setPassword(_:current:migratingLegacyBodiesIn:)` decrypts every live `enc:` body with the old
  salt (typed current password, then the session password; keys derived once per candidate), writes the plaintext
  back (CONT-007 form), saves the data file, and only then writes the new hash/salt. A save that cannot happen
  throws `PasswordError.legacyBodiesNotSaved` and leaves the password unchanged. Undecryptable bodies are kept and
  counted (`LegacyBodyMigration`); `orphanWarning(count:)` and `undecryptableLegacyBodyCount(in:current:)` give the
  flow its warning / confirmation. `LegacyBodyCrypto.decrypt(_:keys:)` added (internal). Tests:
  `PasswordServiceTests.setPasswordMigratesLegacyBodiesBeforeResalting`, `…MigratesWithSessionPassword`,
  `…KeepsSaltWhenMigrationCannotBeSaved`.
  **Not reachable from the menu until W-SHELL passes the store** (cross-owner request: `ShellXDataFlows.setPassword`
  / `ShellFlows.setPassword`). Trash payloads are not rewritten (recorded in Deviations/F1.md).
* **SHELL-193 (V-03)** — `DataStore` no longer folds `/private/tmp/…` onto `/tmp/…`: `appFolder`,
  `setCurrentDataFile`, `adoptExternalDataFile` use `DataStore.lexical` (`URL.standardized`, symlinks kept);
  `isUnderAppFolder` compares `DataStore.comparablePath` (both spellings equal). Test:
  `DataStoreTests.pathsKeepTheSpellingTheUserGave`. The `--smoke-test` status expectation
  (`ShellXSmoke.expectedStatus`, W-SHELL) must switch to the same lexical form (cross-owner request), and the
  DEVIATIONS BD.3.12 sentence about the standardised status path becomes obsolete.
* **V-E2E test housekeeping** — `TempDefaults` (Tests/AACoreTests/Support/TestSupport.swift): a UUID-named
  UserDefaults suite whose `remove()` (idempotent, also from `deinit`) removes the domain, synchronises and deletes
  `~/Library/Preferences/<suite>.plist`. Used in `FoundationHelpersTests.macPreferences`; new test
  `tempDefaultsLeavesNoPlist`. The other six call sites belong to W-SIRE, W-SHELL, W-PERSIST and W-VESSEL
  (cross-owner requests). Plists already left on this Mac by earlier runs (`aa-tests-*`, `aa-sire-tests-*`,
  `persist-tests-*`, `persist-map-*`, `aa.vessel.tests.*`, `aa.tests.shellx.*` in `~/Library/Preferences`) are
  outside `mac/` and were not deleted.

* **ZIP overflow traps (blocker, V2-COMPAT)** — `ZipReader` bounds checks are subtraction form
  (`ZipByteSource.contains(offset:count:)`), the central-directory check is `cdOffset <= size, cdSize <= size -
  cdOffset`, `dataStart` uses `addingReportingOverflow`, and `checkSizes` validates sizes against the archive
  before `data(for:)` / `extract` allocate (Stored csize = usize; Deflate ratio ≤ 1032:1). `RawDeflate.inflate`
  caps its reservation at 1032 × input. The verifier's four crafted archives (now `Fixtures/zip/hostile/`) throw
  `ZipError` from both the file and the memory source, and `BundleService.peekZipLastModified` / `peekBundleSource`
  return nil. Tests: `ZipHostileTests.craftedArchivesThrowInsteadOfTrapping` (×4), `craftedHeadersAreRejectedAtOpen`,
  `overflowingSizesAndOffsets` (6 values × 3 fields × 2 methods × 2 sources), `impossibleDeflateRatioIsCorrupt`.
* **NFD entry names (blocker, V2-COMPAT; F1 half)** — `ZipWriter` NFC-normalises every entry name
  (`ZipWriter.entryName`), so `PersistBundleIO.addTree`'s NFD leaves leave the Mac as the NFC bytes data.json
  stores. Tests: `writerEmitsNFCNames`, the verifier's journey `importedAccentedAttachmentExportsByteIdentical`
  (Café / Peña / 한국어 / Ålesund) and `windowsNFCEntrySurvivesTheRoundTrip` (zip64.zip, backslash.zip). W-PERSIST is
  asked to compare names NFC in its own copy / sweep code (cross-owner request).
* **Duplicate data.json (minor, V2-COMPAT)** — `ZipReader.extractAll` refuses two file entries that land on one
  path (`collisionKey`: separators, NFC, case-insensitive) before writing anything, as Windows' `ExtractToDirectory`
  does in the shared and smart imports; peeks still read the first entry. Tests:
  `duplicateDataJSONIsRefusedBeforeAnythingIsWritten` (dupdata.zip, smart + shared import leave data.json untouched),
  `duplicatesCompareLikeTheFileSystem`.
* **On-disk test defaults (major, V2-SCALE)** — `MacPreferences` gained `MacPreferencesBackend` (UserDefaults
  conforms), `InMemoryPreferences` and `MacPreferences.inMemory()`. `TempDefaults` is now a transitional in-memory
  shim (`InMemoryUserDefaults` overrides every accessor; no suite name, nothing reaches cfprefsd) so the six other
  owners' call sites compile and no longer write `~/Library/Preferences`; it is deleted once they convert (requests).
  `FoundationHelpersTests.macPreferences` → `macPreferencesInMemory`; `tempDefaultsLeavesNoPlist` deleted; new
  `tempDefaultsShimIsInMemory` and the guard `noTestTouchesUserPreferences` (no test source may contain
  `UserDefaults(suiteName`, `UserDefaults.standard`, `removePersistentDomain`, `CFPreferencesSet`). Checked: a run
  of every former TempDefaults suite with no other test process alive left no new file in `~/Library/Preferences`.
* **Save on main (minor, V2-SCALE)** — not changed: ARCH §2.3 binds serialisation on main. Measured split
  (debug): 40 % tree encode, 60 % UTF-8 writing; proposal REQ-F1-02 (Docs/Requests/F1.md) and the cost recorded in
  Deviations/F1.md. The synchronous launch load is F3's (cross-owner request).

+ `Scripts/check-ownership.sh --owner F1` green. No views are owned by F1, so no snapshots were needed.
