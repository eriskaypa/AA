* **D-5 (V-01, DATA-080)** — changing the app password no longer orphans legacy `enc:` bodies silently.
  `PasswordService.setPassword(_:current:migratingLegacyBodiesIn:)` decrypts every live `enc:` body with the old
  salt (typed current password, then the session password; keys derived once per candidate), writes the plaintext
  back (CONT-007 form), saves the data file, and only then writes the new hash/salt. A save that cannot happen
  throws `PasswordError.legacyBodiesNotSaved` and leaves the password unchanged. Undecryptable bodies are kept and
  counted (`LegacyBodyMigration`); `orphanWarning(count:)` and `undecryptableLegacyBodyCount(in:current:)` give the
  flow its warning / confirmation. `LegacyBodyCrypto.decrypt(_:keys:)` added (internal). Tests:
  `PasswordServiceTests.setPasswordMigratesLegacyBodiesBeforeResalting`, `…MigratesWithSessionPassword`,
  `…KeepsSaltWhenMigrationCannotBeSaved`.
  **Not reachable from the menu until W-SHELL passes the store** (cross-owner request: `ShellXDataFlows.setPassword`
  / `ShellFlows.setPassword`). Trash payloads are not rewritten (recorded in Deviations/F1.md).
* **SHELL-193 (V-03)** — `DataStore` no longer folds `/private/tmp/…` onto `/tmp/…`: `appFolder`,
  `setCurrentDataFile`, `adoptExternalDataFile` use `DataStore.lexical` (`URL.standardized`, symlinks kept);
  `isUnderAppFolder` compares `DataStore.comparablePath` (both spellings equal). Test:
  `DataStoreTests.pathsKeepTheSpellingTheUserGave`. The `--smoke-test` status expectation
  (`ShellXSmoke.expectedStatus`, W-SHELL) must switch to the same lexical form (cross-owner request), and the
  DEVIATIONS BD.3.12 sentence about the standardised status path becomes obsolete.
* **V-E2E test housekeeping** — `TempDefaults` (Tests/AACoreTests/Support/TestSupport.swift): a UUID-named
  UserDefaults suite whose `remove()` (idempotent, also from `deinit`) removes the domain, synchronises and deletes
  `~/Library/Preferences/<suite>.plist`. Used in `FoundationHelpersTests.macPreferences`; new test
  `tempDefaultsLeavesNoPlist`. The other six call sites belong to W-SIRE, W-SHELL, W-PERSIST and W-VESSEL
  (cross-owner requests). Plists already left on this Mac by earlier runs (`aa-tests-*`, `aa-sire-tests-*`,
  `persist-tests-*`, `persist-map-*`, `aa.vessel.tests.*`, `aa.tests.shellx.*` in `~/Library/Preferences`) are
  outside `mac/` and were not deleted.
