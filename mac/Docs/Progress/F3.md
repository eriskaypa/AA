## Round 2 — fixed

* **ISO date pickers (V2-J1, V2-J2, V2-J5, V2-DESIGN; DECISIONS Stage V ruling).** `View.aaISODatePicker()` (Design)
  sets `ShellDateDisplay.pickerLocale` (`en_CA`, AACore) on the picker only. Applied in `OptionalDatePicker` and the
  date prompt's field, which covers the task / procedure specifics, task and step editors, quick-work detail, crew
  editor and schedule. Snapshot: the "Set deadline" field reads `2026-10-14` (was `10/14/2026`). The graphical month
  view keeps Locale.current names (rule 14). W-DRIVE's stepper picker is a cross-owner request.
* **CREW-033 Return = Cancel Import (V2-J5, F3 half).** `AlertSpec.defaultIndex`; `DialogPresenter.alert` lays keys out
  with AACore `ShellAlertKeys`; a cancel button that is also the default carries Return and gets ⎋ through a local
  key monitor. W-CREW passes `defaultIndex: 2` (request).
* **Change-password prompt (V2-J6).** "Enter your current password, then the new password and confirm it on the line
  below." — wraps in the sheet (light / dark snapshots).
* **Geometry never restored (V2-J8).** `LaunchCoordinator.restoreGeometryIfReady()` runs from both
  `mainWindowRegistered` and `mainWindowAppeared` (whichever comes second), once, deferred one run-loop turn. Snapshot:
  Ui 100/120/1000×700 → PNG 2000×1400; `Maximized` → zoomed (3024×1774 on this display).
* **Geometry larger than the screen (V2-J8).** `ShellWindowGeometry.clamp` raises to 860×560 and shrinks to the target
  visible frame; snapshot with 3000×9000 → 1512×887 pt.
* **Reminders after leaving safe mode (V2-J8).** `loadDataAndInitUI` → `ShellLoadPlan.startsSkippedServices` →
  prune / reconcile / `ReminderCenter.start`.
* **Quit while "Stop Editing Here" (V2-J8).** `ShellQuitPlan.skipsFinalSave(… stoppedEditing:)`: nothing written or
  pushed, no Save-failed alert.
* **Dark Mode ✓ stale in System appearance (V2-J8).** `ShellAppearance.observeEffectiveAppearance` (KVO) refreshes
  `router.darkModeChecked`. The Settings picker half is W-SHELL's (request).
* **Crash-scan offset global (V2-J8, V2-SCALE).** Per canonical data folder (`CrashLog.scanOffsetKey(appFolder:)`,
  pure `CrashLog.scan`), legacy key migrated once; snapshot runs do not scan.
* **Menu order (V2-J8).** AACore `ShellMenuOrder` (pure) + `AppKitMenuBridge.reorder`: Enter Full Screen last after a
  separator; Export as PDF… and Print… together. Menu dump checked.
* **Crew glyph overflow (V2-J8).** Uncoloured glyph: small scale, `ViewThatFits` steps 10 / 8 pt inside the 20-pt slot
  (safe-mode snapshots, light / dark).
* **Window-wide tint (V2-DESIGN, rule 15).** Root `.tint` removed; `AAProminentButtonStyle` carries `AAColor.tint`.
* **List-pane seam (V2-DESIGN, rule 17).** Root cause: the list-pane material already stopped at the toolbar (checked
  with a red probe); above it the `HSplitView` pane showed the window's grey background while the detail pane's white
  ran under the toolbar. `AAPaneBackground` now lays the material over `AAColor.bg`, which fills the toolbar band:
  Crew and Saved Lists snapshots show one white band across both panes (light / dark). No caller change needed.
