## Fixed

* **Banners break the main window (V-01, blocker).** `ShellBanners` is laid out above `SectionContentHost` in the
  detail `VStack` (no `safeAreaInset`) inside `ShellBannerStack`, a layout that never measures a banner narrower than
  560 pt. Safe-mode: split view 1045.5 → 820 pt; Windows settings + DATA-184: 4211.5 → 820 pt (view dump).
* **Safe mode never names the cause (V-01).** `ShellStatusText.safeModeMessage` carries the 01 §6.5 parenthetical;
  `safeModeMessage(cause:)` / `safeModeStatus(cause:)` lead with `DataLoadError`'s text for `.windowsEncrypted` /
  `.macKeyUnavailable` (LaunchCoordinator D1 alert, `loadDataAndInitUI` status).
* **Read-only copy runs autosave + Drive checks (V-01).** `mainWindowAppeared` starts the autosave timer only for an
  editor; `afterMainShown` runs no Drive check in a read-only copy (`PersistUIBridge.editHere` starts the timer).
* **External-lock second launch quits silently (V-01).** A `.runningHere` that comes only from the DATA-179 external
  lock shows the DATA-172 blocked alert (external-file wording) instead of forwarding and exiting.
* **crash.log not O_APPEND (V-01).** `CrashLog.appendText` = `open(O_WRONLY|O_APPEND|O_CREAT|O_CLOEXEC, 0644)` + one
  `write` (loop only on a partial write); the signal handler adds `O_CLOEXEC`. Test: 300 concurrent appends kept whole.
* **Finder / forwarded `.json` dropped (V-01).** `LaunchCoordinator.enqueueDocuments` keeps `.json` (DATA-173); the
  W-SHELL half (route JSON to Import Database) is a cross-owner request.
* **"second line" prompt (V-01), "every PC" help (V-01).** Texts changed (Deviations F3).
* **⌘Z undo reports "Restored" when nothing came back (V-02, REPO-077).** Empty `undoLastDelete()` → "Nothing to undo."
  and no save; a failed save shows D5 "Save failed".
* **Startup / autosave Drive check awaited (V-03, V-14; SHELL-011/012/013/122, TOOLS-011/024).** The background
  `checkRemoteNewer(interactive: false)` runs detached at startup and after each 5-minute autosave; only the D3
  re-consent box is awaited. Shared-save start, housekeeping, reminders and the Finder document drain follow at once.
* **Menu bridge items vanish on rebuild (V-03; SHELL-509/578/591/592), Enter Full Screen missing (SHELL-640),
  doubled Window separator (SHELL-660).** Every SwiftUI-driven menu gets a `ShellMenuDelegateProxy`; menu dump now
  shows Paste and Match Style ⌥⇧⌘V, ⇧⌘V alias, the four text submenus, ⇧⌘O / ⌘= / ⌃⌘= aliases, Enter Full Screen
  ⌃⌘F and one Window separator.
* **Quick switcher G2 (V-03, SHELL-505).** `CommandRouterCore.state` applies G2 while `keyWin == .switcher`
  (⌘W Close exempt). Test added.
* **Sidebar colour / selection (V-03 SHELL-029, V-DESIGN), brand header (V-DESIGN), Crew badge day change (V-09
  CREW-002).** Tile + native selection + semibold + 2-pt underline; fixed header with naturally wrapping tagline;
  native `.badge`; `NSCalendarDayChanged` re-evaluates the count.
* **Focus stays in a hidden page (V-04, blocker; HIER-025/040/120).** Hidden section roots are `.disabled`; focus
  moves to the sidebar on every section switch and when the main window opens (`ShellFocus`). View dump: no field
  editor in any page at launch; the Equipment Name box is no longer in edit mode.
* **Prompt test vectors (V-06; BUILD-136…139).** `TextPromptRequest` / `TextPromptResult` / `TextPrompting` /
  `ScriptedPrompter` / `TextPromptSession` / `ShellRawFieldDelegate` / `ShellPromptText` moved to AACore
  (`Commands/ShellTextPrompt.swift`); `DialogPresenter` conforms to `TextPrompting`; TV-PR-01…11 are unit tests.
* **Item picker multi mode (V-07, VIEW-208).** Immediate toggles, Space / ↑↓ keyboard, rows exposed as toggles.
* **Window default sizes (V-08; QUICK-120/150).** Search 900×640, Activity log 860×620.
